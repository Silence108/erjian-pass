壹施工管理组织论 · 项目经理 · 风险 · 监理★★☆▶

1. 建设工程项目管理的类型

按管理方立场分：业主方（管理的核心，全过程）、设计方、施工方、供货方、建设项目工程总承包方的项目管理。

业主方项目管理的目标：投资目标、进度目标、质量目标；其项目管理是全过程的管理，是管理的核心。
施工方项目管理的目标：施工成本目标、施工进度目标、施工质量目标（还有安全目标）。选择题常拿"投资目标"混进施工方目标里——投资目标属于业主方。

2. 施工管理的组织（组织论，年年考）

组织论三大工具关系：项目结构图（把项目拆成任务，WBS 思想）→ 组织结构图（谁指挥谁）→ 合同结构图（谁和谁签合同）。三种图长得像，考区别：

图反映连线含义
项目结构图任务分解矩形框 + 直线，无方向
组织结构图指令关系单向箭线（上指挥下）
合同结构图合同关系双向箭线
三种组织结构模式
模式指令源特点
职能组织结构多个各职能部门都能下指令，易矛盾（传统企业）
线性组织结构唯一指令路径单一不打架，但路径可能太长（军队式）
矩阵组织结构纵横两个纵向职能 + 横向项目；指令矛盾时可由总经理协调或授权一方优先（大型项目常用）
指令源数量：职能"多"、线性"一"、矩阵"二"——多一二，念一遍就记住。

3. 施工组织设计

分类：施工组织总设计（以整个建设项目为对象）、单位工程施工组织设计（以单位工程为对象）、施工方案（以分部分项工程为对象）。基本内容五大件：工程概况、施工部署与施工方案、施工进度计划、施工平面图、主要技术经济指标。

4. 项目经理（与二建证书直接相关）

施工企业项目经理是企业法定代表人在项目上的委托代理人，其权限来自企业法定代表人的授权（法定代表人授权委托书）。
  • 项目经理的责任：贯彻法规与企业制度、履行项目管理目标责任书、组织编制项目管理实施规划等
  • 大中型工程项目施工的项目经理必须由取得建造师注册证书的人员担任

5. 施工风险管理

流程：风险识别 → 风险评估 → 风险响应 → 风险控制

风险响应对策四种：规避（不干了/改方案）、减轻、自留（自己扛）、转移（买保险、分包）。选择题给场景判断属于哪种。

6. 建设工程监理

监理的工作性质：服务性、科学性、独立性、公正性。"公正性"指在委托方（业主）与被监理方（施工方）间公正——监理受业主委托但不偏袒业主。
  • 监理主要方式：旁站（关键部位全程盯）、巡视（转着看）、平行检验（自己独立测一遍）
  • 工程建设监理规划：总监理工程师主持编制；监理实施细则：专业监理工程师编制
  • 监理发现严重质量隐患：要求整改 → 拒不整改则报告建设单位；必要时要求暂停施工
"监理受业主委托，所以听业主的"——错。监理具有独立性与公正性，对违法违规行为不能配合业主隐瞒。

7. 项目目标的动态控制（每年必考）

动态控制三步循环：① 目标分解 → ② 收集实际值与计划值定期比较 → ③ 有偏差则纠偏（循环往复）
纠偏措施四类（判断题）：组织措施（调人员、调分工、调流程——最常用且通常最经济）、管理措施（调方法、调合同、调风险应对）、经济措施（资金保障、奖惩）、技术措施（改设计、改方案、改工艺）。给场景判类别是固定题型："调整进度管理的方法和手段"属于管理措施，别选成组织措施。
动态控制的核心环节是"定期比较计划值与实际值"——不是"收集数据"也不是"纠偏"，单选爱抠这个字眼。

8. 施工组织设计的编审与动态管理

  • 施工组织设计由项目负责人主持编制，施工单位技术负责人审批；专项施工方案由项目技术负责人组织编制
  • 规模较大的分部分项工程和专业性较强的项目，单独编制专项施工方案
  • 动态管理：工程设计有重大修改、主要施工方法有重大调整、主要施工资源配置有重大调整、施工环境有重大改变时，及时修改或补充施工组织设计，重新审批后实施

9. 项目管理目标责任书与项目经理权限

  • 项目管理目标责任书：企业法定代表人或其授权人与项目经理协商制定，在项目实施之前签订
  • 项目经理主要权限：参与项目招投标与合同签订、参与组建项目部、主持项目部工作、决定授权范围内的资金投入和使用、参与选择物资供应单位、参与选择并直接管理分包人等
  • 项目经理不得同时担任两个及以上项目的项目负责人（发包人书面同意且非施工高峰期等特殊情形除外，以教材为准）

10. 施工风险的评估与分级

维度说明
风险量 = 概率 × 损失二维评估：发生概率（大/小）× 损失量（大/小）组成风险等级矩阵
概率大 + 损失大高风险——优先规避或转移
概率小 + 损失小低风险——通常自留

施工风险类型四类：组织风险、经济与管理风险、工程环境风险（自然灾害、地质条件）、技术风险（设计缺陷、工艺不成熟）——给场景判类型。

1. 建筑安装工程费的两种拆法（先分清"按什么划分"）

划分方式组成
按费用构成要素人工费 + 材料费 + 施工机具使用费 + 企业管理费 + 利润 + 规费 + 税金
按造价形成分部分项工程费 + 措施项目费 + 其他项目费 + 规费 + 税金
要素看"人材机管利规税"；造价看"分措其规税"。规费税金两边都有。
  • 人工费包括：工资、奖金、津贴补贴、加班加点工资、特殊情况下支付的工资
  • 规费（政府强制缴纳）：社会保险费（养老/失业/医疗/生育/工伤）+ 住房公积金——不得作为竞争性费用
  • 措施项目费：安全文明施工费（不可竞争费）、夜间施工、二次搬运、冬雨期施工、大型机械进出场及安拆等
"安全文明施工费可以让利优惠"——错，它是不可竞争费用，投标不得低于规定标准。

2. 增值税

一般计税方法：税率 9%（建筑业），税前造价不含可抵扣进项税；简易计税：征收率 3%（小规模纳税人或清包工/甲供工程等可选）。具体适用以教材为准。

3. 成本管理的任务链

成本预测 → 成本计划 → 成本控制 → 成本核算 → 成本分析 → 成本考核
  • 成本计划三类：竞争性（投标报价用）、指导性（选派项目经理阶段、责任成本目标）、实施性（项目施工准备阶段、以施工预算为依据编制）
  • 成本核算"三同步"：形象进度、产值统计、实际成本归集三者口径一致
  • 成本分析基本方法：比较法、因素分析法（连环置换，会算）、差额计算法、比率法
因素分析法（连环置换）步骤
  1. 确定分析对象（实际 − 目标的差额）
  2. 各因素按"数量在前、价值在后"排序
  3. 以目标数为基础，依次用实际数替换一个因素，每替换一次算一次差
  4. 各次差额之和 = 总差额（自检手段）

4. 赢得值法（挣值法）——案例与选择双料必考

三个基本值（名字长，用程序员方式记：都是"预算/实际 × 计划量/完成量"的组合）：

符号全称公式含义
BCWS计划工作预算费用计划量 × 预算价（基准线）
BCWP已完工作预算费用（赢得值）已完量 × 预算价
ACWP已完工作实际费用已完量 × 实际价
费用偏差 CV = BCWP − ACWP　（负=超支）
进度偏差 SV = BCWP − BCWS　（负=拖后）
费用绩效指数 CPI = BCWP / ACWP　（<1 超支）
进度绩效指数 SPI = BCWP / BCWS　（<1 拖后）
四个公式全部"赢得值打头"（BCWP 在前）；比的对象——费用找"实际"（ACWP），进度找"计划"（BCWS）。
某工程预算单价 100 元/m³，计划 5 月完成 1000m³；实际完成 900m³，实际单价 110 元/m³。求 CV、SV 并判断状态。
BCWS=1000×100=10 万；BCWP=900×100=9 万；ACWP=900×110=9.9 万。
CV=9−9.9=−0.9 万（超支）；SV=9−10=−1 万（进度拖后）。
口径检查：两个偏差都是 BCWP 打头，费用减实际、进度减计划。

5. 降低成本的措施

四类措施判断题：组织措施（调人调结构，一般不增加费用）、技术措施（改方案改工艺）、经济措施（资金激励审核）、合同措施（索赔、合同条款）。给场景选类别，注意组织措施最经济。

6. 费用细目深挖（选择题细节库）

  • 材料费构成：材料原价 + 运杂费 + 运输损耗费 + 采购及保管费（四项都算材料费，别漏采保费）
  • 施工机具使用费（台班单价七项）：折旧费、检修费、维护费、安拆费及场外运费、人工费（机上司机）、燃料动力费、税费
  • 企业管理费：管理人员工资、办公费、差旅费、固定资产使用费、劳动保险费、工会经费、职工教育经费、财产保险费、财务费、税金（附加税费）以及检验试验费等
检验试验费的归属是经典陷阱：施工企业按规范自行检验的费用计入企业管理费；新结构、新材料的试验费和建设单位要求的对具有出厂合格证明的材料进行检验的费用，由建设单位承担（不在企业管理费里）。

7. 合同价款的支付链条

预付款（开工前，用于备料，随进度款逐次扣回）→ 进度款（按月/按节点计量支付）→ 竣工结算款 → 质量保证金（缺陷责任期满返还）
  • 安全文明施工费应及时预付、专款专用，不得作为竞争性报价
  • 质量保证金预留比例：不得超过工程价款结算总额的 3%；缺陷责任期一般 1 年、最长不超过 2 年（缺陷责任期不等于保修期，保修期见法规科第七章）

8. 成本分析方法补充

  • 比较法的三种对比：实际与目标对比、本期实际与上期实际对比、与本行业先进水平对比
  • 差额计算法：因素分析法的简化形式；比率法：相关比率、构成比率、动态比率
因素分析法完整算例：某分项目标成本 = 500m³ × 400元/m³ × 损耗系数1.05 = 210 000 元；实际 = 520m³ × 410元/m³ × 1.03 = 219 596 元。分析各因素影响。
排序规则：数量在前、价值在后、损耗最后。
① 换产量：520×400×1.05 = 218 400，差 +8 400（产量增加使成本升高 8400）
② 换单价：520×410×1.05 = 223 860，差 +5 460
③ 换损耗：520×410×1.03 = 219 596，差 −4 264（损耗率下降节约 4264）
验算：8 400 + 5 460 − 4 264 = 9 596 = 总差额（219 596 − 210 000）。
考点：替换顺序不能乱（乱了每项影响值全变）；每次只换一个因素；各项差额之和必等于总差额（用来自检）。

9. 施工成本控制的依据

合同文件、成本计划、进度报告、工程变更——注意进度报告也是成本控制依据（成本与进度天生绑定，赢得值法就是明证），单选常考。

2. 双代号网络图：术语翻译（程序员视角）

考试术语程序员术语

3. 六个时间参数与算法

EF = ES + D　　LS = LF − D
TF = LS − ES = LF − EF
FF = min(紧后 ES) − EF　（无紧后：FF = 工期 − EF）
正推(拓扑序)：ES = max(前驱 EF)；工期 T = max(EF)
逆推(逆序)：LF = min(紧后 LS)
TF = 0 的工作连起来 = 关键路径
三条恒真性质：关键工作 ⇔ TF=0；FF ≤ TF 恒成立；关键路径可能不止一条。

5. 考试套路

  • 工期影响判断：工作 X 拖延 n 天——n ≤ TF 不影响；n ＞ TF 则工期延长 (n − TF) 天。案例常配"能否索赔工期"一起考
  • 关键路径转移：压缩某关键工作后，别的路径可能变成新关键路径（赶工题必挖的坑）。自测：把 B 改成 2 天重算——工期 13，关键路径变为 A→D→E
  • 时标网络计划：带时间坐标的网络图，波形线的水平长度 = 自由时差
  • 前锋线比较法：检查日在时标网络上把各工作实际进度点连成折线——点在检查日左侧=拖后、右侧=超前，拖后量与 TF 比判断是否影响工期

6. 进度计划的调整与措施

  • 压缩关键工作持续时间（赶工优先压：费用增加少的、对质量安全影响小的关键工作）
  • 四类进度控制措施：组织（最重要）、管理、经济、技术——"落实进度控制人员与分工"属组织措施，考判断类别

7. 流水施工（组织方式与工期计算）

组织方式特点
依次施工一段干完再干下一段：工期最长、资源投入少、劳动力无法连续
平行施工各段同时开干：工期最短、资源高度集中、现场管理压力大
流水施工各专业队按节拍依次进入各段：工期较短 + 资源均衡 + 专业队连续作业（工程主流方式）
  • 流水参数三类：工艺参数（施工过程数 n）、空间参数（施工段数 m）、时间参数（流水节拍 t、流水步距 K、间歇时间）
  • 等节奏（固定节拍）流水工期公式：T = (m + n − 1) × K + 间歇
某基础工程分 4 个施工段（m=4），有挖土、垫层、砌基础 3 个施工过程（n=3），流水节拍均为 2 天，无间歇。求流水施工工期。
等节拍流水：K = t = 2 天。T = (4 + 3 − 1) × 2 = 12 天。
对比：依次施工 T = 4×3×2 = 24 天；平行施工 T = 3×2 = 6 天但要 4 倍资源。流水 12 天是"工期与资源的折中"——这个对比本身就是选择题考点。

  • 时标网络计划：横轴带时间刻度；实箭线水平投影长度 = 持续时间；波形线长度 = 自由时差；自始至终不出现波形线的通路即关键线路（识图题直接数波形线）

  1. 返工重做或更换器具设备的，重新验收

进阶：招标方式与程序细节

  • 公开招标（发招标公告）vs 邀请招标（向 3 个以上特定法人或组织发投标邀请书）；国有资金占控股或主导地位的依法必须招标项目应当公开招标（符合法定情形方可邀请招标）

  • 招标文件的澄清或修改：在投标截止时间至少 15 日前书面通知所有获取招标文件的潜在投标人；不足 15 日的，顺延投标截止时间

进阶："视为串通投标"五情形（高频必背）

① 不同投标人的投标文件由同一单位或个人编制；② 委托同一单位或个人办理投标事宜；③ 投标文件载明的项目管理成员为同一人；④ 投标文件异常一致或报价呈规律性差异；⑤ 投标文件相互混装；（另：投标保证金从同一单位或个人账户转出）。——见到这些情形直接判"视为串通"，中标无效。

"属于串通"（有主观合意）：投标人之间协商报价、约定中标人、约定部分投标人放弃投标或中标等；招标人与投标人串通：开标前开启投标文件并泄露、泄露标底、授意撤换修改投标文件等。

四种解决方式

和解、调解、仲裁、诉讼。仲裁与诉讼是"二选一"关系：有有效仲裁协议的，法院不予受理（劳动争议除外——它是仲裁前置）。

仲裁三大特点（选择题常客）

  • 自愿性：以双方有效的仲裁协议为前提；仲裁协议应约定明确的仲裁委员会
  • 一裁终局：裁决作出即生效，不能上诉；可依法申请撤销或不予执行
  • 不公开审理为原则（保护商业秘密）；仲裁协议具有独立性（合同无效不影响仲裁条款效力）

诉讼管辖（建工人必知）

建设工程施工合同纠纷按不动产纠纷确定管辖——由工程所在地人民法院专属管辖（不能协议选别处）。
  • 民事诉讼实行两审终审；普通诉讼时效 3 年
  • 证据的种类与保全；申请财产保全需提供担保（细节以教材为准）

结构受力常识（理解型送分点）

  • 荷载分类：永久荷载（结构自重等恒载）、可变荷载（人员、家具、风、雪等活载）、偶然荷载（爆炸、撞击）

地基与基础

土方开挖十六字诀：开槽支撑、先撑后挖、分层开挖、严禁超挖。案例背景一旦出现"一挖到底""超挖后回填虚土"就是找你挑错。

  • 基坑降水（明沟排水、井点降水）；回填土分层夯实并取样检测

钢筋与模板

  • 钢筋连接三法：绑扎搭接、机械连接、焊接；受力钢筋接头位置相互错开、宜设在受力较小处
  • 钢筋隐蔽验收：浇筑混凝土前必须完成（品种、规格、数量、位置、保护层）
底模拆除的混凝土强度要求（背这张表）：跨度 ≤2m → ≥50% 设计强度；2–8m → ≥75%；＞8m 及悬挑构件 → 100%。侧模：强度能保证表面及棱角不受损伤即可拆。

混凝土工程

  • 浇筑：分层浇筑分层振捣，控制自由倾落高度（过高会离析）
  • 施工缝留设原则：留在结构受力（剪力）较小且便于施工的部位；柱留在基础顶面、梁的下面等；有主次梁楼盖顺次梁方向浇筑，施工缝留在次梁跨中 1/3 范围
  • 养护：覆盖浇水一般不少于 7 天，掺缓凝剂或有抗渗要求的不少于 14 天
  • 冬期施工界定：连续 5 天平均气温低于 5 摄氏度
  • 大体积混凝土：控制水化热温升、内外温差（防裂），测温是案例常考背景

砌体与防水

  • 砌筑"三一法"：一铲灰、一块砖、一挤揉；转角与交接处同时砌筑，不能同时砌的留斜槎（普通砖墙斜槎水平投影长度不小于高度的 2/3）
  • 每日砌筑高度有限制（约一步架高，具体数字以教材为准）；填充墙砌至梁板底附近停歇后再补砌顶紧
  • 屋面防水：先找坡找平再防水，卷材搭接顺水流方向；细部节点（阴阳角、落水口）附加层是通病高发区
  • 室内防水：卫生间蓄水试验（验收必做）
案例背景里"雨天浇筑混凝土未采取措施""养护 3 天就上人施工""填充墙一天砌到梁底并立即塞顶"都是标准错误点——见到就写"不妥，正确做法是……"。

一栋楼的主流程

前期：拿地 → 勘察 → 设计出图 → 报建审批 → 招投标
施工：三通一平 → 基础工程 → 主体结构 → 砌体围护 → 屋面防水 → 装饰装修+机电安装（穿插）
收尾：竣工验收 → 备案 → 交付（保修期开始）

主体每层循环：绑钢筋 → 支模板 → 浇混凝土 → 养护 → 拆模 → 上一层。这是实务施工技术的叙事主线。

地基与基础
地基 vs 基础地基是土（承载建筑的土层），基础是结构构件（埋在土里的混凝土部分），考试严格区分
独立基础一根柱子下一个墩子，低层框架常用
条形基础墙下一条混凝土长条，砖混常用
筏板基础整栋楼下一块大板，像船筏，高层常用
桩基础打桩深入好土层，软土/超高层用
结构体系
砖混结构砖墙承重+混凝土楼板，老式多层住宅
框架结构柱梁骨架承重，墙只是填充，办公楼常用
剪力墙结构钢筋混凝土墙承重抗侧力，高层住宅主流
承重墙 vs 填充墙承重墙动不得；装修砸墙只能砸填充墙
现浇 vs 装配式现场浇混凝土 / 工厂预制现场拼装（政策方向）
混凝土与钢筋
C30混凝土强度等级，数字=立方体抗压强度标准值(MPa)
坍落度混凝土稀稠度指标
养护浇完保湿保温慢慢变硬，不养护会裂会掉强度
试块浇筑时留的样品送实验室测强度（质量证据）
钢筋保护层钢筋外必须裹的混凝土厚度，防锈防火
模板工程混凝土的模具，浇前支、达强度后拆
安全与合同
三宝四口五临边安全帽/带/网；楼梯口/电梯井口/预留洞口/通道口；各种没栏杆的边

总包/分包可分包部分工程，但主体结构不能分包、禁止转包

Q1 地基和基础的区别？
地基是土（自然物），基础是结构构件（人造物）。
Q2 主体一层楼的施工循环？
绑钢筋 → 支模板 → 浇混凝土 → 养护 → 拆模 → 上一层。
Q3 五方责任主体？项目经理属于哪方？
建设、勘察、设计、施工、监理。项目经理属于施工单位。

立方体抗压强度标准值 30MPa。

三宝：安全帽/安全带/安全网。四口：楼梯口/电梯井口/预留洞口/通道口。五临边：未设防护的各种临边部位。
