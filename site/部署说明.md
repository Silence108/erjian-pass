# 部署说明（Cloudflare Pages + KV 云同步）

> 目标：免费上线学习站，获得一个手机电脑通用的网址，打卡进度多端同步。
> 前置：电脑装有 Node.js（终端跑 `node -v` 有版本号即可）；一个邮箱。

## 一、首次部署（约 15 分钟）

### 1. 注册 Cloudflare

<https://dash.cloudflare.com/sign-up> 邮箱注册，免费版即可。

### 2. 创建 KV 存储（存打卡进度用）

登录后台 → 左侧 **Storage & Databases → KV**（旧版界面在 Workers & Pages 下）
→ **Create namespace** → 名字填 `EJIAN_KV` → 创建。

### 3. 命令行部署本目录

```bash
cd "D:/Desktop/www/luanqibazao/二建备考/site"
npx wrangler pages deploy . --project-name=ejian-study
```

- 首次运行会自动安装 wrangler 并弹浏览器让你登录授权
- 提示 Create a new project 时回车确认，production branch 用默认值
- 成功后输出形如 `https://ejian-study-xxx.pages.dev` 的网址

### 4. 绑定 KV（同步功能的关键一步）

后台 → **Workers & Pages** → 进入 `ejian-study` 项目 → **Settings** →
找到 **Bindings**（或 Functions 标签下的 KV namespace bindings）→ Add：

- Variable name（变量名）：`EJIAN_KV` （必须一字不差）
- KV namespace：选第 2 步建的那个

保存后**重新执行一遍第 3 步的 deploy 命令**（绑定只对新部署生效）。

### 5. 验证

浏览器打开你的 `*.pages.dev` 网址 → 首页"多端同步"卡片 →
生成新码 → 启用 → 状态显示"本设备进度已上云"即全部成功。

## 二、手机使用

1. 手机浏览器打开同一网址（iPhone 用 Safari，安卓用 Chrome/Edge）
2. 菜单 → **添加到主屏幕**，以后点图标全屏打开，断网也能看（PWA 离线缓存）
3. 首页"多端同步"输入电脑上生成的**同一个同步码** → 启用 →
   弹窗选"确定＝用云端进度覆盖本设备" → 两端从此自动同步

## 三、同步机制说明

- 同步码即身份，无需注册：打开页面自动拉取云端，打卡后约 2.5 秒自动推送
- 冲突策略：新时间戳覆盖旧时间戳（正常"手机学完回电脑"的用法不会冲突）
- 同步码抄在别处保存；换设备输码即恢复；"停用"不删云端数据
- 数据只有打卡状态（无个人信息），泄露同步码的最大后果是进度被人看到/改掉

## 四、以后更新内容

内容源文件是 `二建备考/二建学习站.html`（团团更新它），发布三步：

```bash

cp 二建学习站.html site/index.html
cd site && npx wrangler pages deploy . --project-name=ejian-study
```

注意：Service Worker 有离线缓存，部署新版后设备上**第二次打开**才生效，正常现象。

## 五、已知事项

- `pages.dev` 域名国内访问速度因地区和时段而异，慢时多试；长期嫌慢可绑自己的域名（Cloudflare 上绑域名不强制备案，但国内速度本质取决于网络环境）
- 免费额度（KV 每天 10 万读 1000 写）对个人使用是天文数字，放心用
- 本地双击 `二建学习站.html` 依然可用（同步功能自动隐藏为提示），完全离线的兜底
