# 部署说明（GitHub 自动部署 + Cloudflare Pages + KV 云同步）

> 工作流：改内容 → `git push` → Cloudflare 自动部署上线，手机电脑同一网址。
> 本地 git 仓库已初始化完成（分支 main），以下从 GitHub 开始。

## 一、注册与 KV 存储（一次性）

1. 注册 Cloudflare：<https://dash.cloudflare.com/sign-up>（免费版够用）
2. 创建 KV：后台 → **Storage & Databases → KV** → **Create namespace** → 名字 `EJIAN_KV`

## 二、推送到 GitHub（一次性）

1. 打开 <https://github.com/new> 新建仓库：
   - 名字建议 `ejian-study`
   - **务必选 Private（私有）**——仓库里含你的备考笔记和个人信息
   - 不要勾选任何初始化选项（README/gitignore 都不要，本地已有）
2. 回到终端执行（把 `<你的用户名>` 换成 GitHub 用户名）：

```bash
cd "D:/Desktop/www/luanqibazao/二建备考"
git remote add origin https://github.com/<你的用户名>/ejian-study.git
git push -u origin main
```

首次 push 会弹浏览器让你登录 GitHub 授权（Windows 凭据管理器接管，一次即可）。

## 三、Cloudflare 连接仓库（一次性，核心步骤）

1. 后台 → **Workers & Pages → Create → Pages → Connect to Git**
2. 授权 GitHub（可只授权 `ejian-study` 这一个仓库）→ 选中它
3. 构建配置（**逐项核对**）：
   - Framework preset：`None`
   - Build command：**留空**
   - Build output directory：`.`
   - 展开 Root directory (advanced)：填 `site`  ← 关键，页面和云函数都在这个子目录
4. 点 Deploy，首次部署完成后得到 `https://ejian-study-xxx.pages.dev`
5. **绑定 KV**：项目 → Settings → Bindings（或 Functions 下的 KV namespace bindings）→ Add：
   - Variable name：`EJIAN_KV`（一字不差）
   - KV namespace：选第一步建的那个
6. 绑定后到 Deployments 页对最新部署点 **Retry deployment**（或随便 push 一次）——绑定只对新部署生效

> 如果你之前已用 `wrangler pages deploy` 建过 Direct Upload 项目：同一项目**不能**切换成 Git 模式，直接按上面新建 Git 项目、绑定 KV，然后删掉旧项目即可（KV 里的同步数据不受影响）。

## 四、验证

打开网址 → 首页"多端同步"→ 生成新码 → 启用 → 显示"本设备进度已上云"即全链路成功。

## 五、手机使用

1. 手机浏览器打开同一网址（iPhone 用 Safari，安卓用 Chrome/Edge）
2. 菜单 → **添加到主屏幕**，之后全屏打开、断网可用
3. 输入与电脑相同的同步码 → 启用 → 选"用云端进度覆盖本设备"

## 六、日常更新（以后每次就这三行）

```bash
cd "D:/Desktop/www/luanqibazao/二建备考"
git add -A && git commit -m "更新讲义"
git push
```

push 后 Cloudflare 约 1 分钟自动部署；设备上**第二次打开**生效（离线缓存机制）。

- **内容唯一源：`site/index.html`**（团团今后直接更新它）；根目录的 `二建学习站.html` 是历史快照，不再维护
- 推非 main 分支会得到独立预览网址，可用来试改动不影响线上

## 七、同步机制与已知事项

- 同步码即身份，免注册：打开自动拉取、打卡后约 2.5 秒自动推送；新时间戳覆盖旧的
- 同步码抄好保存，换设备输码即恢复；"停用"不删云端数据
- 数据只有打卡状态，无敏感信息；KV 免费额度（日 10 万读 1000 写）远超个人所需
- `pages.dev` 国内访问速度因地区时段而异；长期嫌慢可在项目里绑自定义域名
- 本地双击 `site/index.html` 依然可用（同步自动降级为提示），完全离线兜底
